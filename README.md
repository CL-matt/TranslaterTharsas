# 📌 项目介绍

本项目包含多个模块，旨在提供高效的翻译功能。

## 📂 目录结构说明

- **`Audio/`** - 音频文件（不建议下载，后续会在HTML中使用）
- **`Dicts/`** - 核心词库（所有重要数据均存放于此）
- **`Lenguaje/`** - 语言核心设定（涉及主要翻译逻辑）
- **`Modulos/`** - 所有需要使用的 Python 数据库
- **`Traductor/`** - 翻译器核心部分
- **`Pronct/`** - 未完成部分（开发中）
- **`test.py`** - 翻译器主体代码
